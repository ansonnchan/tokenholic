Silkscreen is drawn on an 8-pixel grid and has capital forms only. Set it at
multiples of 8 pixels so its edges land on whole pixels. Neither family's
Reserved Font Name is used for a modified version, because nothing here is
modified; replacing a file means updating its checksum above.
