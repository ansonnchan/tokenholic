How many tokens did your coding agents burn?

tokenholic reads the usage records Claude Code and Codex already keep on your machine, totals them in your terminal, and ranks you against the friends you invite.

npx @tokenholic/cli

No account needed. Nothing uploads until you claim.

How it works

  1. Run it

    One command scans your local agent records and opens the dashboard. No account, no setup.

  2. See your numbers

    Tokens, an API-equivalent estimate, models, and sources, per day and all-time. All of it local.

  3. Claim your spot

    Sign in with GitHub from the terminal. Uploading starts only after you confirm what is sent.

  4. Compare

    Create a group, send an invite, and watch the board move. Go public only if you choose to.

What it touches

Read locally

  • Claude Code CLI sessions
  • Claude Desktop Code, Agent, and Cowork sessions
  • Codex CLI and Codex Desktop sessions

Only token counts and model IDs are taken from them. Ordinary chat apps are never read.

Sent on claim

  • Token counts by category
  • The model ID each agent recorded
  • Which agent, and a one-minute UTC time bucket
  • Service tier and a coarse prompt-size band, when recorded
  • Your account and device identifiers

tokenholic show-data prints the exact payload before you ever sign in.

Never sent

  • Prompts and responses
  • Source code and diffs
  • Tool inputs and command text
  • File paths, project, repository, and branch names
  • Provider credentials
  • Raw session transcripts

Reading the numbers

$ EST
An estimate of what the same tokens would cost at API list prices. It is never what you spent; a subscription bills differently.
≥
A lower bound. Some usage had no known price, or an agent did not record every category.
—
Unknown. An unknown value is never shown as zero.
RANK
Usage is reported by each member's own machine. A board is for bragging rights, not proof.
PUBLIC
Profiles, groups, and the global board stay private until their owner opts in from the terminal.

This site is read-only: no sign-in, no cookies, no analytics. Everything else happens in your terminal.
